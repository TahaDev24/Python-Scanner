# Security Policy

## Reporting a vulnerability

Please do not publish secrets, exploit details, or private project data in a public issue.

Use GitHub's private vulnerability reporting feature if enabled for this repository. Otherwise, contact the maintainer through a private channel listed on the GitHub profile.

## Scope and limitations

Python Scanner is a static analysis aid, not a security certification tool. It does not execute the project being scanned and does not guarantee detection of all vulnerabilities. Findings can be false positives or false negatives.

When reporting a scanner issue, include the rule ID, Python version, operating system, and a minimal sanitized example.
